# Internal history

Planning artifacts kept for archaeology. **These are not documentation.**

`superpowers/plans/` and `superpowers/specs/` were written *before* the code they
describe, addressed to an agent executing the work. Every one is implemented, and
several describe a design that shipped differently — the browser-profile spec was
superseded by the session-unification spec a day later, for example.

Read the code, or [the documentation](../site/), for how the system behaves today.
Nothing here is maintained, and nothing here is published to the docs site.
