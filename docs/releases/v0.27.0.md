# workbench v0.27.0

_2026-09-06_

Headline: **workbench has a mark, an animated hero, and a landing page.** The
placeholder letter tile is gone everywhere; a shared brand package owns the new
mark and the canvas "swarm" that builds it from outlined tool shapes.

## New

- **The Node W.** A wire between five nodes: four hollow tool shapes — circle,
  square, triangle, diamond — and one filled hub, the endpoint the agent talks
  to. Shipped as data plus an SVG renderer in `packages/brand`, with a build that
  emits the favicon, touch icon, OG image and lockups.
- **Swarm login hero.** The mark assembles from thousands of outlined shapes:
  an orbiting lane entrance, a rigid 3D slab that turns with the pointer, depth
  shading, a bright rim, fade-and-reseed idle, and an ambient field of loose
  shapes. Respects reduced motion, pauses when hidden, drops glow under budget.
- **Landing site** (`site/`, Netlify): hero with the docker one-liner,
  integration strip and counts read from the plugin registry at build time, a
  typed terminal replay, portal screenshots, three pillars. Builds without a
  browser.
- **Docs and README** use the new mark; the docs topbar links to the site.

## Fixes

- **Plugin tool count refreshed.** Docs and README said 178; the registry holds
  194 across 16 integrations. The site prints the live number.
- **Image build without Chromium.** The Docker builder skips PNG rendering and
  the portal falls back to committed brand assets; turbo now passes the brand
  env vars through.
- **Release workflow installs Chromium** before building, matching CI.

**Upgrade note:** no schema or config changes. `latest` moves here.
